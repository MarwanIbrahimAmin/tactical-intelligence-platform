# AI-Powered Football Tactical Intelligence Platform ⚽🤖

> **Graduation Project Prototype** — Transforming raw football tracking data into explainable, evidence-linked tactical intelligence.

---

## 📌 1. The Problem

Modern football analytics relies heavily on Electronic Performance and Tracking Systems (EPTS) and Computer Vision to gather millions of spatial data points per match. However, existing sports performance platforms suffer from critical limitations:

1. **Information Overload & Raw Data Complexity**: Performance analysts and coaches are inundated with dense heatmaps and raw coordinates that fail to convey actionable tactical insights.
2. **"Black-Box" Analytics**: Existing tools state *what* happened (e.g., "the defensive shape broke down") without explaining *why*, *when*, or offering verifiable data. Coaches cannot trust or act on recommendations they cannot inspect.
3. **Static Averages vs. Dynamic Match Context**: Traditional dashboards aggregate metrics across 90 minutes. They ignore phase shifts (e.g., Build-Up vs. Defensive Transition) and fail to capture instantaneous deviations between planned tactical intent and match reality.

---

## 💡 2. The Solution & Core Idea

The **AI-Powered Football Tactical Intelligence Platform** bridges the gap between raw spatial tracking data and actionable coaching decisions by establishing a transparent, context-aware analytics engine.

### Core Idea: Expected vs. Actual Tactical Intelligence

Instead of merely reporting static metrics, the platform estimates the **Expected Tactical State** for any given match scenario (based on phase, ball position, and tactical model) and compares it against the **Actual Tactical State** derived from spatial tracking.

## 🔥 3. Key Differentiator: Explainable & Evidence-Linked AI

Every insight generated by the platform adheres to strict explainability standards. An insight **never** presents an unbacked claim. Each insight contains:

- **Tactical Context**: Exact match timestamp, phase (e.g., *Defensive Transition*, *Pressing*), and ball location.
- **Expected vs. Actual Quantification**: Measured metrics (Width, Depth, Compactness Area, Line Spacing) compared against context-driven target ranges.
- **Deviation Severity**: Categorized as *Aligned*, *Moderate*, or *Significant*.
- **Confidence & Data Quality**: Clear metrics showing model confidence percentage and underlying tracking sensor quality.
- **Visual Evidence**: Interactive 2D pitch keyframes displaying player positions, movement vectors, centroid lines, and supporting numerical trend graphs.

## ✨ 4. Key Features & Platform Modules

### 1. ⏱️ 90-Minute Dynamic Match Simulation Engine
- Interactive timeline scrubber simulating player movements, team width, line spacing, and ball trajectories across all 90 minutes.
- Real-time recalculation of tactical metrics, alignment percentages, and deviation scores as time advances.

### 2. 🏟️ Interactive Tactical Pitch Visualizer
- Dynamic 2D pitch with home/away team positioning, velocity vectors, centroids, defensive line depth, and attacking width boundaries.
- **Expected Overlay Mode**: View target spatial positioning overlaid on top of actual player positions to highlight tactical misalignment.

### 3. 🔍 Evidence Review Hub
- Deep-dive evidence cards linking tactical pattern breakdowns (e.g., *High Press Breakdown*, *Defensive Separation*) to time-series charts, metric trends before/after events, and video placeholders.

### 4. 📊 Team Shape & Physical Performance
- Compactness area ($m^2$), line spacing metrics, sprint counts, acceleration/deceleration statistics, high-intensity distance ($km$), and player zone occupancy heatmaps.

### 5. 📡 Data Quality & Telemetry Assurance
- Real-time data quality monitoring, including pitch calibration error in meters, identity switch tracking, missing frame ratios, and track continuity percentages.

### 6. 🧠 How AI Works (ML Pipeline & Feature Fusion Modal)
- Interactive ML architecture inspector demonstrating how 24 raw spatial tracking features fuse into 7 compact tactical dimensions for model inference.

## 🚀 6. Getting Started

### Prerequisites

Ensure you have Node.js (v18 or higher) and npm installed:
```bash
node -v
npm -v
```

### Installation & Local Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/MarwanIbrahimAmin/tactical-intelligence-platform.git
   cd tactical-intelligence-platform
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to `http://localhost:5173` in your web browser.

5. **Build for production**:
   ```bash
   npm run build
   ```
